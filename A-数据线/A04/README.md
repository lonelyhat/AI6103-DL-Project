# A04 正式候选与选材证据统计

基于 A03 a03-v2、G02 g02-v1 和 D08 八批正式选材，统计 80 题 × 2 种索引 × 5 种策略。正式题覆盖五种题型，偏好题未纳入。结果反映标注证据的保留情况，问答正确率以 E04/F04 为准。

## 交付文件

- output/candidate_metrics.jsonl 包含 160 条候选统计，每题每个索引一条。
- output/selection_metrics.jsonl 包含 800 条选材统计，包括批次、配置、材料指纹、候选与选材证据结果及归因。
- output/summary.json 汇总各索引和策略的统计、数据和配置指纹。
- output/formal_eval.jsonl 包含正式题证据及参考答案，供评价使用。

这些文件包含题型或证据标注，供评价分析使用。选择及回答继续读取 A03 公共文件和 D08 阅读输入。

## 口径和验证

复用 A02 Evidence.retention()，按照选中轮所含消息 ID 的并集统计，重复消息去重。不可达证据计入分母。每题每种设置输出 candidate 和 selected 指标。

- candidates_missing 表示前 100 个候选未覆盖全部证据。
- all_retained 表示选材覆盖全部证据。
- selection_missed 表示候选覆盖全部证据，且存在一个仅由证据轮组成、实际序列化后不超过 2048 Token 的完整覆盖组合，但实际选材未覆盖全部证据。
- minimal_cover_over_budget 表示所有包含必要证据的最小覆盖组合，按 D01 序列化和冻结分词器计数都超过 2048 Token。组合只包含证据轮，且移除任一轮即无法覆盖全部证据。分词长度可能非单调，因此该标签明确描述已枚举范围。

计算前检查全部 D08 压缩包和冻结输入指纹，通过项目的 D.D08.verify_delivery。正式评价数据从清洗数据重新构建，SHA-256 与 G02 记录一致。使用与 G02 冻结指纹一致的 Llama 分词器复算证据轮组合。

独立按 D08 selected_message_ids 与真实证据消息集合求交，800/800 条与 A02 结果一致。与 G02 独立证据筛查交叉核对，完整证据 317 条、零证据 187 条，K0/K1 候选证据齐全题数分别为 78/79，均一致。

    python "A-数据线/A04/run_a04.py" \

      --tokenizer /path/to/llama-tokenizer \
      --output "A-数据线/A04/output"
