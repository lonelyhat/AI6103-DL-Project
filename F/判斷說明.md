# F03 人工判斷說明（v0.4，2026-11-18）

> 本文件是人工判斷的規則，與 `SCORING_CONFIG.md`（評分設定）搭配使用。F03 校準與 F05 雙人判斷共用。
> 例子只描述情況，不列盲判表編號，避免影響之後的判斷者。

## 怎麼填

打開盲判表（例如 `dev5_blind_sheet.csv`，Excel 可直接開），每一列讀「問題、參考答案、模型回答」，填寫：

| 欄位 | 填法 |
|---|---|
| 人工判斷(1對/0錯) | 必填，只填 `1` 或 `0` |
| 猜測(Y) | 見下方「猜測的定義」。有勾填 `Y`，沒勾留白 |
| 不確定(Y) | 依下面的規則仍拿不定主意時填 `Y`，之後討論。有勾填 `Y`，沒勾留白 |
| 理由 | 判錯、勾猜測或不確定時寫一句原因 |

勾選欄填 `Y`、`V`、`✓`（不分大小寫）都視為有勾；空白或 `N` 視為沒勾。建議統一填 `Y`。

**注意**
- 判完之前**不要打開**對照檔與成員檔（`*_DO_NOT_OPEN.csv`，記錄編號對應的方法），也不要看 judge 的評分結果或其他判斷者的表。這些檔案由 F 線負責人保管。
- 存檔時選「CSV UTF-8」，另存成自己的檔名，例如 `dev5_blind_sheet_名字.csv`。
- 回答很長時可在 Excel 中把「模型回答」欄設為自動換行。

## 判斷依據：論文 p.20 Figure 10

| 題型（`question_type`） | 判對的條件 |
|---|---|
| `single-session-user`、`single-session-assistant`、`multi-session` | 回答包含正確答案，或包含得出正確答案的完整中間步驟；只答出一部分算錯 |
| `knowledge-update` | 可同時提到舊資訊，最後的答案是更新後的值即算對 |
| `temporal-reasoning` | 同一般題型；天數、週數換算後差 1 天不扣分 |
| `single-session-preference` | 參考答案是**評分細則**，不是標準答案。回答正確地記得並運用使用者過去提過的個人資訊即算對，不需要涵蓋細則中的每一點（細則待偏好題校準後補充） |

拒答題（題號以 `_abs` 結尾）不在主實驗範圍，由 H06 另訂規則。

## 兩個勾選欄的意思

兩欄互相獨立，可以都勾、只勾一欄或都不勾，**都不改變 1/0 的判法**。

| 欄位 | 記的是 | 什麼時候勾 |
|---|---|---|
| 猜測 | **模型的回答中看得出來**的猜測 | 見下方定義 |
| 不確定 | **判斷者**對自己的 1/0 有沒有把握 | 依規則兩種判法都說得通、規則沒涵蓋、看不出最後結論時。規則明確但你不同意時**不勾**，在理由欄寫意見 |

### 猜測的定義

> **猜測 ＝ 給出了具體答案（數字、名稱、日期），而且回答中明白寫出這個答案依賴假設或替代資料。**

判斷者只看得到問題、參考答案和模型回答，**看不到對話歷史**，所以只標記回答本身看得出來的猜測（明說的假設、用其他日期頂替等）。答案在對話歷史中有沒有依據，不在盲判時判斷，需另做證據核對（F02）。猜測欄只是分析用的標記，不改變 1/0 的判法。

| 情況 | 猜測 |
|---|---|
| 自行假設日期或數字，算出具體答案（例：「假設今天購買、7 天前收到，所以是 1 週」） | Y |
| 用其他日期頂替找不到的日期，算出具體答案（例：找不到購買日，改用提問日來算） | Y |
| 說找不到資料，沒有給答案 | 不勾 |
| 只給方向性的常識推測，沒有具體答案（例：「夏威夷通常比較貴，應該花得比較多」） | 不勾 |
| 從對話內容推論，即使推論錯（例：看到三個播放清單名稱，推論「至少 3 個」） | 不勾 |

## Figure 10 沒寫清楚的情況（本專案補充規則）

| 編號 | 情況 | 判法 |
|---|---|---|
| R1 | 猜對：具體答案依賴假設，答案卻正確 | 依論文規則判 `1`，並勾「猜測」。準確率照論文計算，猜對的題數另外報告 |
| R2 | 先說無法回答，又附帶推測 | 推測中含有正確答案才判 `1`，否則 `0` |
| R3 | 推理過程出現正確數字，最後結論錯誤 | 以**最後結論**為準 |
| R4 | 列出多個候選答案或一個範圍，沒有選定 | 判 `0` |
| R5 | 單位或格式不同但意思相同（`$270` 與 `270 dollars`） | 判 `1` |
| R6 | 答案正確，但附帶的其他事實有錯 | 只看是否答出問題要的答案；附帶錯誤不扣分，可在理由中註記 |
| R7 | 帶保留語的數字答案 | 見下表 |

**R7 細則**（題目問確切數量，以參考答案 20 為例）

| 回答 | 判法 |
|---|---|
| "at least 3"（數字錯） | `0` |
| "about 20" / "around 20" | `1`，數字就是正確答案 |
| "at least 20"（數字對、只說是下限） | `0`：題目問確切數量，回答只給了下限 |
| "between 15 and 25" | `0`，同 R4 |

只有題目本身問「至少多少」時，才把下限當作答案判斷（例如問「至少去過幾次」、參考答案 20，回答 "at least 20" 判 `1`）。
