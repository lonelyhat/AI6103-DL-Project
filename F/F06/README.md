# F06 主結果與差值區間（g02-v1）

80 道正式題 × 10 種設定（K0/K1 × R/MMR/C/Q/FL），共 800 筆，預算 2048 token，閱讀模型 e02-v2。分數用 F04 judge 評分（`f03-v1`、`gpt-4o-2024-08-06`），也就是團隊歸檔的 [8 批評分檔](../scores/)，batch-05 取第一次評分。F05 人工定案和 GPT-4o 一致 120/121（99.17%），所以主結果沿用 judge 分數（見 [F05 README](../F05/g02-v1/README.md)）。

## 主要配對差值

一題相當於 1.25 個百分點。表中的「錯→對」指 A 對、B 錯；交互項一列改填 I>0 和 I<0 的題數。

| 比較 | 差值（百分點） | 95% 信賴區間 | 錯→對／對→錯 |
|---|---|---|---|
| K0：Q − C | −1.2 | [−11.0, +7.7] | 7／8 |
| K1：Q − C | +3.8 | [−2.5, +10.1] | 5／2 |
| K0：Q − R | −8.8 | [−19.8, +1.3] | 6／13 |
| K1：Q − R | −8.8 | [−19.5, +1.3] | 6／13 |
| K1：Q − FL | **+12.5** | **[+2.5, +22.8]** | 14／4 |
| Q：K1 − K0 | +5.0 | [−1.3, +12.3] | 6／2 |
| R：K1 − K0 | +5.0 | [−2.5, +12.7] | 7／3 |
| K1-R − K0-Q | **+13.8** | **[+3.8, +24.1]** | 15／4 |
| I = (Q1 − C1) − (Q0 − C0) | +5.0 | [−3.8, +13.9] | I>0 9 題／I<0 5 題 |

其餘比較（Q − MMR、K0：Q − FL、C、MMR、FL 的 K1 − K0）見 [f06_paired_diffs.csv](f06_paired_diffs.csv)。

- 80 題下，多數差值的區間包含 0，**無法確認差異**。Q（按題覆蓋）沒有穩定優於 C 或 R。
- 區間不含 0 的只有兩項：K1 下 Q 優於 FL；只加事實索引（K1-R）優於只換覆蓋選材（K0-Q）。
- 證據齊全時，正確率為 0.68–0.94；證據放得下卻沒選齊時，只有 0.17–0.32（依設定而異）。後者在各設定中佔 26–54 題，是主要的失分來源。

## 方法

- **配對**：同一題在兩種設定下比較，每題的差值是 1、0 或 −1，交互項可到 ±2。
- **信賴區間**：80 題屬於 78 個 A03 證據組，共享證據的題目不獨立，所以以**證據組**為單位做 cluster bootstrap：抽 10,000 次，seed 20261120，取 2.5% 和 97.5% 分位數。
- **檢查**：800 筆＝80 題 × 10 設定，無重複，無 `api_error`。每筆的 `history_sha256` 都和 A04 一致，代表評分和證據統計用的是同一份材料；每題都有證據組。任一項不符，程式就停止。
- **輸入**：
  - [A03 正式題](../../A-数据线/A03/output/public/formal_questions.jsonl)
  - [A03 篩選紀錄](../../A-数据线/A03/output/eval/selection_audit.jsonl)（含證據組）
  - [A04 證據統計](../../A-数据线/A04/output/selection_metrics.jsonl)
  - [G02 分析計畫](../../G/G02/README.md)
