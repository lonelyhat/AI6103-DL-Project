## 报告可引用的结果

- **最高观测正确率为 K1＋R 的 42/80（52.5%）**。相对 K0＋R 的配对差值为 ＋5.0 个百分点，95% 区间为 [−2.5, ＋12.7]。K0 下 Q−C 为 −1.2 个百分点，K1 下为 ＋3.8 个百分点，交互项为 ＋5.0 个百分点，三者区间均跨 0。可报告没有观察到 Q 的稳定优势。区间按 78 个证据组做配对 bootstrap，补充对照按探索性结果解读。
- 已记录的一次性建库耗时为 **K0 967.45 秒、K1 2,053.00 秒**，两者为各阶段记录用时的合计。K1 包含现有补抽开销，复用事实的历史抽取费用仍未知。F07 的全量抽取成本是敏感性估算。回答模型加载另列，评分费用属实验支出。
- 结论适用于本轮 LongMemEval-S 五类可回答题及冻结的阅读模型、评分模型和预算。原论文的 LongMemEval-M 成绩仅作背景，正式改进幅度来自同题、同条件的内部对照。F05 一致率对应抽取的复核样本。

## 离线复核入口

在本次交付所在的工作树根目录执行。需要能读取上表的固定提交。逐条核对与复算只需 Python 和 Git，使用归档的评分、回答和证据数据。

```powershell
New-Item -ItemType Directory -Force runs/g03-e04 | Out-Null
python G/G03/audit.py --output runs/g03-audit.json
python C05/c05_analyze.py

$scores = (Get-ChildItem F/scores/formal_g02-v1_batch-*.jsonl | Sort-Object Name).FullName
python F/src/evaluation/f06_analysis.py --scores $scores --out-dir runs/g03-f06

git -c core.autocrlf=false archive --format=tar --output=runs/g03-e04.tar 95438df71b0730d58ab260d97f4528e3b3228e72 E/E04/results/g02-v1
tar -xf runs/g03-e04.tar -C runs/g03-e04
python F/src/evaluation/f07_cost.py --e04-dir runs/g03-e04/E/E04/results/g02-v1 --scores $scores --out-dir runs/g03-f07
```

如需重跑 D08 原离线交付检查，在 **5b1c02f** 的工作树执行 `python -m D.D08.verify_delivery`。当前 main 的 F03 规则文档与 Judge 程序在正式执行后更新，严格检查冻结源码应使用 D08 固定提交。对原清洗数据或真实分词器的重新计算可按 [A04 说明](../../A-数据线/A04/README.md)与 [A05 说明](../../A-数据线/A05/README.md)执行。本次使用归档的原文、评价输入和分词回执做交叉核对。
