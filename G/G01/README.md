## 复核和验收

从项目根目录执行。脚本只读取现有归档并复算，不调用模型或 Judge API。Windows 检出的 CRLF 会按 Git 仓库的 LF 口径核对源档哈希。

```bash
python -B G/G01/audit.py --output G/G01/audit_5q.json
```

拿到 F 保存的真实 F02 预算版评分后，在本地加 `--f02-scores`。它会逐项比对评分键、最终状态、发送给 Judge 的回答或答案指纹，以及与运行记录的标签一致性。测试样例中的 `scores_dev_K0.jsonl` 不可作为正式评分原件。

```bash
python -B G/G01/audit.py --f02-scores /path/to/dev_K0_R_2048_e02.jsonl --output G/G01/audit_5q.json
```
