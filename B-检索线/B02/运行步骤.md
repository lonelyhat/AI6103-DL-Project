## 4. 提交作业

先查自己有哪些 partition 和 QoS：

```bash
ssh wang2496@10.96.189.12
sacctmgr show user wang2496 withassoc format=user,partition,qos
```

TC2 指南示例里是 `MGPU-TC2` 和 `normal`，以查到的为准。提交：

```bash
cd ~/B02/repo
sbatch --account=stud --partition=MGPU-TC2 --qos=normal \
  --output="$HOME/B02/logs/b02-%j.out" \
  --error="$HOME/B02/logs/b02-%j.err" B-检索线/B02/job_b02.sh
squeue -u wang2496
```

提交时显式设置绝对日志路径，避免默认相对路径缺失导致作业无法启动。作业依次跑本组脚本、官方对照和自动检查，按指南的 `normal` 上限（1 张 GPU、30G 内存、6 小时）申请了 1 小时、28G。如果你的限额不同，改脚本里的 `--mem` 和 `--time`。

日志：`~/B02/logs/b02-<作业号>.out` 和 `.err`。
