# B02：首批五题 K0 候选交接

已完成 A01 首批五题的 K0 原文检索：用 Stella V5 1.5B 将当前问题与每个历史轮次的**用户发言**分别编码，按相似度排序，每题输出前 100 条候选。**AI 回复不参与此次检索打分**；候选编号对应完整原始轮次，供下游读取用户发言及紧邻下一条消息（通常是 AI 回复）。K0 不加入抽取事实。

## D 线读取什么

| 内容 | 仓库位置 |
| --- | --- |
| 候选编号、排名、分数 | `B-检索线/B02/candidates/dev_K0.jsonl` |
| 问题文本 | `A-数据线/A01/output/public/dev_questions.jsonl` |
| 完整轮次原文 | `A-数据线/A01/output/public/turns/{question_id}.jsonl` |

候选文件共 5 行，每题一行，包含 A01-v2 公共字段及 `candidates: [{turn_id, rank, score}]`。用 `turn_id` 关联原文即可，不必重复复制原文。分数是相似度，不是答案正确概率。

D01 CLI 可用 `--questions` 关联公开问题表、`--turns-dir` 关联公开轮次。D01 自行基于完整轮次计算 TF-IDF 特征，本次不交付检索向量。选择与回答环节不读取 `map/`、`eval/` 或官方检索日志。

`budget_tokens=2048` 表示下游的历史阅读预算；检索阶段仍交付完整前 100 条候选，由 D 线继续选择预算内材料。

## 已通过的验证

- 五题各 100 条；排名、有限且降序的分数、编号唯一性和完整原文映射检查通过。
- 五题前 100 名的编号与顺序均与官方程序完全一致；官方日志没有数值分数，未进行官方分数逐项比较。
- 真实候选关联公开问题及原文后，通过 D01 输入及跨字段校验。
- 作业 `50055` 在 TC2N01 / NVIDIA A40 正常完成（`0:0`），总用时 4 分 36 秒；本组五题检索合计约 74.6 秒，不含模型加载和官方对照。
