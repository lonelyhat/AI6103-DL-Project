# D03：真实候选上的 MMR 去重选择

入口：在仓库根目录运行 `python -m D.selection_batch --strategies MMR ...`，完整命令见 D/README.md。

复用 D01 的已测试核心，并通过新的批量适配器接入 B02/A01-v2。
每轮在能放入完整历史预算的候选中最大化 `r - lambda*d`；
r 为当前问题候选原始检索分数的 min-max 归一化（全部相等则设为 1），
d 为候选与已选原始完整轮次之间的最大 TF-IDF 余弦相似度。
特征只读取用户及紧邻消息的原文，不读取事实、参考答案或证据标签。

默认 lambda=0.5，是开发起点，尚未经过 D06 调参。
同分按原始 rank 升序确定。没有可行候选、最佳分数不大于 0 或候选耗尽时停止。
每次重新评估未选候选，因此预算不足不等于永久删除；与 D02 的一次 rank 扫描不同。

选中步骤保存原始分数、归一化相关性、冗余、lambda、最终分数和真实历史 Token 成本。
阅读文本沿用 D02 序列化：时间排序、message_id 去重、完整消息保留、不截断。
输出包含批次指纹及逐步贪心重放验证。结果只能说明材料选择与预算实现通过，不能推断答案正确率。
