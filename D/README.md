# 固定阅读预算下的历史对话选择

长期对话问答需要从大量历史记录中选出有限的阅读材料。检索排名衡量单条记录与问题的相关程度，但排名靠前的记录可能内容重复，也可能占用过多空间，导致回答所需的其他信息被排除。

D线研究检索之后的材料选择：在统一Token预算内，以完整原始轮次为选择单元，比较相关性、去重、长度成本和信息覆盖的作用。实验同时使用原文索引K0与事实增强索引K1；事实影响检索，阅读材料和选择特征仍来自原始对话。

- [D01：五种选择方法与统一接口](D01/README.md)
- [D02：相关性选择与预算材料构建](D02/README.md)

材料处理遵循A01-v2：轮次ID用于定位，时间顺序由sort_key确定；重叠轮共享的消息按message_id去重。统一序列化后的实际文本长度作为预算依据，选择结果为回答、证据保留分析和成本统计提供可追溯输入。
